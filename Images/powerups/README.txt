Power-up icon packs
===================

Each folder in here is one pack. The folder name is the name shown in
HUD Customization > POWER-UP ICONS (for example "Black Ops 1").

To add a pack: make a new folder, put PNGs in it named exactly as below,
then restart the game. Any icon a pack leaves out stays the Black Ops 7 one.
Square PNGs with transparency work best (128x128 or larger).

Power-ups (each has two names; supply both)
  sat_ui_hud_zm_powerup_icon_instakill.png     Insta-Kill
  ui_icon_powerup_ob_instakill.png             Insta-Kill
  sat_ui_hud_zm_powerup_icon_doublepoints.png  Double Points
  ui_icon_powerup_ob_double_points.png         Double Points
  sat_ui_hud_zm_powerup_icon_firesale.png      Fire Sale
