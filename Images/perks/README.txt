Perk icon packs
===============

Each folder in here is one pack. The folder name is the name shown in
HUD Customization > PERK ICONS (for example "Black Ops 1").

To add a pack: make a new folder, put PNGs in it named exactly as below,
then restart the game. Any icon a pack leaves out stays the Black Ops 7 one.
Square PNGs with transparency work best (128x128 or larger).

Perks
  ui_icon_perks_zm_juggernaut.png       Juggernog
  ui_icon_perks_zm_quickrevive.png      Quick Revive
  ui_icon_perks_double_tap.png          Double Tap
  ui_icon_perks_zm_speedloader.png      Speed Cola
  ui_icon_perks_zm_staminup.png         Stamin-Up
  ui_icon_perks_zm_phdslider.png        PhD Slider
  ui_icon_perks_zm_deadshot.png         Deadshot
  ui_icon_perks_zm_mulekick.png         Mule Kick
  ui_icon_perks_zm_elemental_pop.png    Elemental Pop
  ui_icon_perks_zm_deathperception.png  Death Perception
  ui_icon_perks_melee_macchiato.png     Melee Macchiato
  ui_icon_perks_vulture_aid.png         Vulture Aid
  ui_icon_perks_widows_wine.png         Widow's Wine
  ui_icon_perks_wisp_tea.png            Wisp Tea

Power-up packs live in Images\powerups (see the README there).
